# Nvidia-NIM Project

(i) Built an end-to-end RAG (Retrieval-Augmented Generation) application using LangChain integrated with Nvidia NeMo endpoints.

(ii) Developed a Streamlit interface to load documents, create embeddings using Nvidia models, and enable interactive Q&A.

(iii) Implemented Nvidia API integration with foundation and open-source models like LLaMA 3, supporting fast and scalable inference.

(iv) Designed a modular workflow for document loading, text-splitting, embedding creation, and vector-store retrieval to ensure reusability.
